## Install

| Cask | Command | Requirements |
| :--- | :--- | :--- |
| <img src="https://raw.githubusercontent.com/FantasmaGlad/Bobine/main/Assets/Images/logo_bobine_icon.png" width="20" height="20" valign="middle" alt=""> **Bobine** | `brew install --cask fantasmaglad/bobine/bobine` | Apple Silicon |
| <img src="https://raw.githubusercontent.com/FantasmaGlad/bobine-deploy/main/crates/bobine-deploy/assets/icons/32x32.png" width="20" height="20" valign="middle" alt=""> **Bobine Deploy** | `brew install --cask fantasmaglad/bobine/bobine-deploy` | Apple Silicon, Intel |

Each cask follows the latest Stable release and links its command: `bobine`, `bobine-deploy` (alias `bdp`).
