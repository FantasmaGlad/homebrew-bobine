# homebrew-bobine

Homebrew tap for [Bobine](https://github.com/FantasmaGlad/Bobine) and [Bobine Deploy](https://github.com/FantasmaGlad/bobine-deploy). French: [README.fr.md](README.fr.md).

| Cask | Command | Requirements |
| :--- | :--- | :--- |
| <img src="https://raw.githubusercontent.com/FantasmaGlad/Bobine/main/Assets/Icons/os/apple.svg" width="20" height="20" valign="middle" alt="macOS"> **Bobine** | `brew install --cask fantasmaglad/bobine/bobine` | Apple Silicon |
| <img src="https://raw.githubusercontent.com/FantasmaGlad/Bobine/main/Assets/Icons/os/apple.svg" width="20" height="20" valign="middle" alt="macOS"> **Bobine Deploy** | `brew install --cask fantasmaglad/bobine/bobine-deploy` | Apple Silicon, Intel |

Each cask follows the latest Stable release of its repository and links its command (`bobine`; `bobine-deploy` and its short alias `bdp`). The casks are generated by `scripts/cask.py` and installed on macOS in CI before being published. `bobine-deploy` replaces the former `bobine-assistant` cask.
