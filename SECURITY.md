# Security Policy

Do not report a vulnerability in a public issue. Use the [private report](https://github.com/FantasmaGlad/homebrew-bobine/security/advisories/new) or [security@bobine.fit](mailto:security@bobine.fit) (OpenPGP `23CA D324 C507 FB0F 97E6 AECA 6E4C 020E F8BD FEB2`).

The policy, its scope and its timelines are published at <https://security.bobine.fit> and in [`/.well-known/security.txt`](https://bobine.fit/.well-known/security.txt). Each cask pins the SHA-256 digest of the image it installs, taken from the `SHA256SUMS` file of the release.
